# Download folder

Pick the folder for your build. Everything in it goes into Agent Builder; nothing else in this repository is needed for setup.

- [`standard-build`](standard-build): paste `instructions.txt`, upload the eight files in `knowledge`.
- [`skills-build`](skills-build): paste `instructions.txt`, upload the five files in `skill-zips` one at a time, without unzipping them. Only for organisations in the Microsoft Frontier Program.

Step-by-step setup and the values to paste are in the [main README](../README.md#set-up-in-agent-builder).

# Skills, readable versions

Each folder holds the `SKILL.md` of one custom skill, so you can read it on GitHub before you upload it. The upload-ready packages are in [`download/skills-build/skill-zips`](../download/skills-build/skill-zips). Each package contains this `SKILL.md` plus a `references` folder with copies of the knowledge files the skill uses, from [`download/standard-build/knowledge`](../download/standard-build/knowledge).

- [verify-microsoft-sources](verify-microsoft-sources/SKILL.md)
- [security-licensing-advisor](security-licensing-advisor/SKILL.md)
- [security-marketing-writer](security-marketing-writer/SKILL.md)
- [security-deep-research](security-deep-research/SKILL.md)
- [technical-and-claim-review](technical-and-claim-review/SKILL.md)

Custom skills are in preview and available only to organisations in the Microsoft Frontier Program. Setup steps are in the [main README](../README.md#choose-your-build).
